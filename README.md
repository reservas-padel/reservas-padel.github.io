# Reservas de pádel · Vals Sport

Página pública para que los alumnos reserven su clase de pádel.

- Los huecos, plazas y reservas se gestionan desde una hoja de Google (Apps Script).
- Esta página solo muestra los datos y envía las reservas a la API del script, sin usar las cuentas de Google del navegador.
- Probar el diseño sin datos reales: añade `?demo` al final de la dirección.
